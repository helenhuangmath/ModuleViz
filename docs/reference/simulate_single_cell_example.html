simulate_single_cell_example

Simulate a small single-cell time course

Description

Generate single-cell counts whose sample-level averages follow the temporal patterns of the bundled heatmap_example data: 60 genes, two conditions, four time points, and two replicates, with several cell types per sample. Intended for examples, tests, and tutorials.

Usage

simulate_single_cell_example(cells_per_sample = 20,
  cell_types = c("T_cell", "Monocyte"), seed = 1)

Arguments

cells_per_sample

Number of cells per sample and cell type.

cell_types

Names of the simulated cell types.

seed

RNG seed; NULL uses the current RNG state. The global random-number stream is left unchanged.

Value

A SingleCellExperiment (a SummarizedExperiment if the SingleCellExperiment package is not installed) with a counts assay and the cell metadata columns SampleID, Condition, TimeHr, Replicate, and CellType.

Examples

sce <- simulate_single_cell_example(cells_per_sample = 10)
sce
table(sce$CellType, sce$TimeHr)
