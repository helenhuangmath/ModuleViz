load_real_timecourse_example

Load supported public time-course example datasets

Description

List and load public time-course datasets from Bioconductor timecoursedata, returning plain matrices and metadata ready for ModuleViz workflows.

Usage

available_real_timecourse_datasets()

load_real_timecourse_example(dataset = c("sorghum_leaf", "sorghum_root",
  "influenza_mouse"), top_n_features = 1000, genotype = "BT642",
  condition = NULL, group = NULL, min_week = 3, log_transform = TRUE)

Arguments

dataset

Dataset key.

top_n_features

Number of most-variable features to keep.

genotype, condition

Optional filters for sorghum datasets.

group

Optional filter for influenza groups.

min_week

Minimum sorghum week retained.

log_transform

Use log2(x + 1) before feature selection.

Value

available_real_timecourse_datasets() returns a data table. load_real_timecourse_example() returns a list with mat, meta, column-name fields, source text, and a citation hint.

Examples

available_real_timecourse_datasets()

if (requireNamespace("timecoursedata", quietly = TRUE)) {
    ex <- load_real_timecourse_example("influenza_mouse", top_n_features = 200)
    dim(ex$mat)
    head(ex$meta)
}
