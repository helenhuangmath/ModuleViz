multi_cluster

Cluster several omics layers into shared modules, linked by gene

Description

Align any number of omics layers (for example RNA, ATAC, H3K27ac, and H3K27me3) by gene and assign every gene to one temporal module. Each layer is z-scored within itself and collapsed to one row per gene, so layers with different feature types (genes, peaks, CUT&RUN regions) line up row for row.

Usage

multi_cluster(layers, meta = NULL, sample_col = "SampleID",
  time_col = "TimeHr", group_col = NULL, cluster_by = 1, gene_of = NULL,
  aggregate = c("mean", "top"), gene_set = c("intersect", "reference"),
  balance_layers = TRUE, ...)

Arguments

layers

Named list of at least two layers. Each entry is a longi object or a raw features x samples matrix. Names become panel titles.

meta

Sample metadata for raw-matrix layers: one data frame shared by all layers, or a named list with one data frame per layer. longi layers carry their own metadata.

sample_col, time_col, group_col

Metadata columns for raw-matrix layers, as in longitudinal_cluster().

cluster_by

Which layer defines the modules: a layer name or index (default: the first layer), or "joint" to cluster the concatenated per-gene profiles of every layer together.

gene_of

Function mapping row IDs to gene symbols, either one function for every layer or a list with one per layer (by name or position). By default the first layer's IDs are used as-is and every other layer takes the text after the last underscore, so peak1243_Pdcd1 maps to Pdcd1.

aggregate

How to collapse several features per gene: "mean" averages them, "top" keeps the feature with the strongest |z|.

gene_set

"intersect" keeps genes present in every layer; "reference" keeps every row of the cluster_by layer and leaves layers without that gene as NA.

balance_layers

Joint clustering only: weight each layer's columns by 1/sqrt(number of columns) so a layer with many samples does not dominate the distance.

...

Passed to longitudinal_cluster() (k, method, stability, ...) when the clustering layer is a raw matrix, and always for cluster_by = "joint".

Details

With cluster_by set to a layer, that layer alone defines the modules and row order and the other layers are displayed in the same order, as in dual_heatmap(). With cluster_by = "joint" a module groups genes whose trajectories agree across all layers. Joint clustering needs a time column in every layer's metadata. To collapse replicates, pass per-layer longitudinal_cluster(..., aggregate_replicates = TRUE) objects.

Value

An object of class multi_longi: a list with layers (per-layer aligned z-score matrix and metadata), cluster, genes, membership, stability, reference (the longi object the modules came from), and params.

Examples

data("heatmap_example", package = "ModuleViz")
mat <- heatmap_example$mat
atac <- mat[rep(rownames(mat), each = 2), ]
rownames(atac) <- paste0("peak", seq_len(nrow(atac)), "_", rownames(atac))
x <- multi_cluster(list(RNA = mat, ATAC = atac),
                         meta = heatmap_example$meta, sample_col = "SampleID",
                         time_col = "TimeHr", group_col = "Condition",
                         k = 4, stability = FALSE)
