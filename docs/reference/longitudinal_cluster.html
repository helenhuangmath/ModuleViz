longitudinal_cluster

Cluster longitudinal features into temporal modules

Description

Z-score feature trajectories, cluster them into modules, order modules by their temporal peak, and return a longi object for plotting and export.

Usage

longitudinal_cluster(mat, meta = NULL, sample_col = "SampleID",
  time_col = "TimeHr",
  group_col = NULL, id_col = NULL, k = 8, method = "kmeans",
  is_zscore = FALSE, aggregate_replicates = FALSE, seed = 1, nstart = 50,
  hclust_method = "ward.D2", dist_method = "euclidean", stability = TRUE,
  n_resample = 50, subsample_frac = 0.8, assay = NULL)

zscore_rows(mat)

collapse_columns(mat, grp, group_levels = NULL)

Arguments

assay

Assay to use when mat is a SummarizedExperiment. Defaults to the first of logcpm, logcounts, normcounts, vst, rlog that is present, otherwise the first assay.

mat

Features-by-samples data: a numeric matrix or data frame, or a SummarizedExperiment (including SingleCellExperiment, e.g. the result of pseudobulk_cells).

meta

Sample metadata with one row per sample. Optional for a SummarizedExperiment, whose colData is used by default.

sample_col

Metadata column containing sample IDs matching the column names of mat. For a SummarizedExperiment without meta the column names are used directly.

time_col

Metadata column giving the time point of each sample. Numeric time is ordered numerically, a factor by its levels, and character values by first appearance.

group_col

Optional metadata column for treatment, genotype, or condition.

id_col

Optional feature-ID column when mat is a data frame.

k

Number of modules.

method

Clustering algorithm: "kmeans" (default), "hierarchical", "pam", "clara", or "fuzzy". See Details.

is_zscore

Set TRUE when values are already row z-scores.

aggregate_replicates

Average replicate columns within group-by-time before clustering. Metadata columns that are constant within each group-by-time cell are kept.

seed, nstart, hclust_method, dist_method

Clustering controls. seed makes the randomised algorithms reproducible without altering the global random-number stream; NULL uses the current RNG state. nstart applies to k-means, hclust_method to hierarchical clustering, and dist_method ("euclidean", "correlation", or any dist method) to hierarchical, PAM, and fuzzy clustering.

stability, n_resample, subsample_frac

Cluster stability controls.

grp

Column grouping vector for collapse_columns().

group_levels

Optional output group order.

Details

The clustering algorithms differ in what they assume and how they scale:

"kmeans"

Fast and the usual choice for z-scored trajectories.

"hierarchical"

Deterministic agglomerative clustering (hclust_method, dist_method); useful with correlation distance.

"pam"

Partitioning around medoids; more robust to outlying features than k-means, but needs a full distance matrix.

"clara"

PAM on repeated sub-samples; scales to tens of thousands of features.

"fuzzy"

Fuzzy c-means (fanny). Features are assigned to their strongest module and the membership table gains a Membership column (0-1) showing how firmly each feature belongs there.

Value

A longi object containing ordered z-scores, cluster labels, membership tables, centroids, stability, metadata, and parameters.

See Also

choose_k, longitudinal_heatmap, pattern_lineplot, pseudobulk_cells

Examples

data("heatmap_example", package = "ModuleViz")
obj <- longitudinal_cluster(heatmap_example$mat, heatmap_example$meta,
                            sample_col = "SampleID", time_col = "TimeHr",
                            group_col = "Condition", k = 4, n_resample = 5)
obj
head(obj$membership)

## another algorithm: fuzzy c-means adds a membership score
fz <- longitudinal_cluster(heatmap_example$mat, heatmap_example$meta,
                           time_col = "TimeHr", group_col = "Condition",
                           k = 4, method = "fuzzy", stability = FALSE)
head(fz$membership)

## a SummarizedExperiment works directly
se <- SummarizedExperiment::SummarizedExperiment(
    assays = list(logcounts = heatmap_example$mat),
    colData = heatmap_example$meta)
colnames(se) <- heatmap_example$meta$SampleID
longitudinal_cluster(se, time_col = "TimeHr", k = 4, stability = FALSE)

z <- zscore_rows(heatmap_example$mat)
collapse_columns(z, heatmap_example$meta$TimeHr)[1:3, ]
