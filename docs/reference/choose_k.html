choose_k

Choose a module count with elbow and silhouette diagnostics

Description

Scan candidate module counts and report total within-cluster sum of squares, mean silhouette width, and a simple distance-to-line elbow suggestion.

Usage

choose_k(z, k_range = 2:20, method = "kmeans", nstart = 25,
  hclust_method = "ward.D2", dist_method = "euclidean", seed = 100,
  file = NULL, chosen_k = NULL, annotate_k = TRUE, base_size = 10)

Arguments

z

Row-z-scored matrix.

k_range

Integer vector of module counts to test.

method, nstart, hclust_method, dist_method, seed

Clustering controls, as in longitudinal_cluster.

file

Optional PDF diagnostic plot path.

chosen_k

Optional module count actually used downstream. When supplied it is drawn as a solid line beside the dashed elbow, keeping the diagnostic figure consistent with the module count used in the rest of the analysis. The elbow is only a heuristic and is frequently not the k worth reporting.

annotate_k

If FALSE, draw the bare elbow curve with no marker lines and no subtitle.

base_size

Base font size for the diagnostic plot.

Value

A data table with diagnostics and attribute suggested_k.

Note

The elbow is a heuristic, not an answer. Prefer the k that separates programmes you can interpret: a k that merges two biologically distinct modules is worse than one that splits a module in two, because a merged module reports the average of programmes that do not agree.

Examples

data("heatmap_example", package = "ModuleViz")
z <- zscore_rows(heatmap_example$mat)
diag <- choose_k(z, k_range = 2:6)
diag
attr(diag, "suggested_k")
