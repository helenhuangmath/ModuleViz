pseudobulk_cells

Summarise single cells into pseudobulk profiles

Description

Group single cells by sample, cell type, condition, and time point (or by pseudotime bin) and sum or average their expression. The result is a SummarizedExperiment with one column per pseudobulk profile, ready for longitudinal_cluster and the rest of the ModuleViz workflow.

Usage

pseudobulk_cells(x, meta = NULL, time_col, sample_col = NULL,
  group_col = NULL, celltype_col = NULL, assay = NULL,
  fun = c("sum", "mean"), normalize = NULL, min_cells = 10,
  n_bins = NULL, features = NULL, prior_count = 1, scale_factor = 1e6)

Arguments

x

A SingleCellExperiment or SummarizedExperiment, a Seurat object, or a features-by-cells matrix (dense or sparse).

meta

Per-cell metadata, one row per cell. Required for a matrix; optional otherwise, where it replaces the object's own cell metadata.

time_col

Metadata column giving the time point (or pseudotime) of each cell.

sample_col

Optional column identifying the biological sample or replicate each cell came from.

group_col

Optional column for a condition, genotype, or treatment.

celltype_col

Optional column of cell-type labels. When given, every cell type gets its own pseudobulk profiles.

assay

Assay (or Seurat assay) to read. Defaults to counts for fun = "sum" and logcounts for fun = "mean".

fun

"sum" (default; for raw counts) or "mean" (for values that are already log-normalised).

normalize

Add a log2 counts-per-million assay named logcpm. Defaults to TRUE for fun = "sum"; ignored for fun = "mean".

min_cells

Pseudobulk profiles built from fewer cells are dropped.

n_bins

Optional number of equal-sized bins to cut a continuous time_col, such as pseudotime, into. The bin index then becomes the time and the mean of the original values is kept as <time_col>_mean.

features

Optional subset of features to keep.

prior_count, scale_factor

log2-CPM settings: log2(count / library_size * scale_factor + prior_count).

Details

Cells are grouped by every column supplied among sample_col, celltype_col, group_col, and time_col. Supplying sample_col keeps biological replicates separate, which is what allows longitudinal_cluster() to show replicate variation or average over it with aggregate_replicates = TRUE.

ModuleViz clusters features across an ordered set of samples, so it does not operate on individual cells: summarising first also removes most of the drop-out noise of single-cell counts. For a Seurat object the counts layer is read for fun = "sum" and the data layer for fun = "mean"; this needs the SeuratObject package.

Value

A SummarizedExperiment. With fun = "sum" it has the assays counts and (unless normalize = FALSE) logcpm; with fun = "mean" a single assay of averaged values. Its colData holds the grouping columns, every other metadata column that is constant within a profile, and n_cells.

See Also

longitudinal_cluster, select_variable_features, simulate_single_cell_example

Examples

sce <- simulate_single_cell_example(cells_per_sample = 10)

## one profile per sample (replicates kept separate)
pb <- pseudobulk_cells(sce, time_col = "TimeHr", sample_col = "SampleID",
                       group_col = "Condition", min_cells = 5)
pb

obj <- longitudinal_cluster(pb, time_col = "TimeHr", group_col = "Condition",
                            k = 4, stability = FALSE)
obj

## one profile per cell type x sample
pb_ct <- pseudobulk_cells(sce, time_col = "TimeHr", sample_col = "SampleID",
                          group_col = "Condition", celltype_col = "CellType",
                          min_cells = 5)
dim(pb_ct)

## a continuous ordering (e.g. pseudotime) cut into bins
pb_bins <- pseudobulk_cells(sce, time_col = "TimeHr", n_bins = 4)
SummarizedExperiment::colData(pb_bins)
