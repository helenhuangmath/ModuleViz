write_memberships

Write module membership and summary tables

Description

Export module membership, centroid, and stability tables from a longi or multi_longi object.

Usage

write_memberships(obj, file = NULL, prefix = NULL, write_extras = TRUE)

Arguments

obj

A longi or multi_longi object. A multi_longi has no centroid table, so only membership and stability are written.

file

Optional membership table path.

prefix

Output prefix used when file is not supplied.

write_extras

Also write centroids and stability tables.

Value

The membership table invisibly.

Examples

data("heatmap_example", package = "ModuleViz")
obj <- longitudinal_cluster(heatmap_example$mat, heatmap_example$meta,
                            time_col = "TimeHr", k = 4, n_resample = 5)
prefix <- file.path(tempdir(), "moduleviz_tables")
write_memberships(obj, prefix = prefix)
list.files(tempdir(), pattern = "moduleviz_tables")
