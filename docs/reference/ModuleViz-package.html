ModuleViz-package

Longitudinal Omics Heatmaps and Temporal Module Plots

Description

Cluster longitudinal omics features into temporal modules, draw ordered ComplexHeatmap heatmaps, summarize module trajectories, test modules for gene-set enrichment, and align paired omics layers such as RNA and ATAC by gene. Bulk matrices, SummarizedExperiment objects, and single-cell data are supported.

Details

Core workflow functions are longitudinal_cluster, longitudinal_heatmap, pattern_lineplot, and write_memberships. Several omics layers are aligned by gene with multi_cluster and multi_heatmap. Modules are tested for gene-set enrichment with module_enrichment. Single-cell data are summarised into pseudobulk profiles with pseudobulk_cells. Public real-data examples can be loaded with load_real_timecourse_example.

Value

No return value; this page documents the package as a whole.
