module_correlation_heatmap

Gene-gene correlation heatmaps per temporal module

Description

Correlate the features within each temporal module against each other across the ordered samples and draw the resulting correlation matrix as a heatmap. A coherent module appears as a solid block of high correlation; visible sub-blocks mean the module is averaging over more than one programme. module_correlation_summary() returns the mean within-module correlation for every module without drawing anything.

Usage

module_correlation_heatmap(obj, clusters = NULL,
  method = c("pearson", "spearman"), max_genes = Inf,
  select = c("top", "random"), cluster_genes = TRUE,
  corr_palette = "rdbu", corr_limits = c(-1, 1), col_fun = NULL,
  show_gene_names = NULL, label_top_n = 15, label_fontsize = 8,
  legend_fontsize = 9, title_fontsize = 11, file = NULL,
  width = 4.5, height = 4.5, square = TRUE, title = NULL, seed = 1)

module_correlation_summary(obj, method = c("pearson", "spearman"),
  max_genes = Inf, select = c("top", "random"), seed = 1)

Arguments

obj

A longi object from longitudinal_cluster().

clusters

Module names to draw. Defaults to all modules.

method

Correlation method, "pearson" or "spearman".

max_genes

Optional cap on features per module. Defaults to Inf, so every feature in the module is used; set a finite value to subsample large modules for speed.

select

Subsampling rule: "top" keeps the strongest-signal features (largest max |z|), "random" draws an unbiased sample.

cluster_genes

Order features by hierarchical clustering on correlation distance, which makes sub-blocks visible.

corr_palette

Continuous palette: "rdbu" (default) or "viridis".

corr_limits

Length-2 correlation range for the colour scale.

col_fun

Optional explicit colour function; overrides corr_palette.

show_gene_names

Show every feature name. Defaults to TRUE when 60 or fewer features are shown, and FALSE beyond that, where printing all names would be unreadable.

label_top_n

When names are too crowded to print in full, mark this many features instead, chosen as those with the largest |z| - the features moving most across the series. Set 0 to disable marking.

label_fontsize

Font size for feature names.

legend_fontsize, title_fontsize

Font sizes for the legend and title.

file

Optional output path. A .pdf path collects all modules into one multi-page PDF; any other extension writes one file per module with the module name inserted before the extension.

width, height

Figure size in inches.

square

Draw the heatmap body as a square, sized to the largest square that fits the figure after the dendrogram, labels, title, and legend.

title

Optional title prefix; the module name and size are appended.

seed

RNG seed used when select = "random".

Value

For module_correlation_heatmap(), invisibly a named list with one entry per module holding cor, mean_cor, n_total, n_shown, labelled (the feature names actually drawn), and heatmap. For module_correlation_summary(), a data.table with columns Cluster, N, NShown, and MeanCor.

Examples

data("heatmap_example", package = "ModuleViz")
obj <- longitudinal_cluster(
  heatmap_example$mat, heatmap_example$meta,
  sample_col = "SampleID", time_col = "TimeHr",
  k = 4, stability = FALSE
)
module_correlation_summary(obj)
