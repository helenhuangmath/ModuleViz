module_enrichment

Gene-set enrichment of temporal modules

Description

module_enrichment() tests every module for over-representation of each gene set with a one-sided hypergeometric test. The result can be passed to the enrichment argument of longitudinal_heatmap, multi_heatmap, and dual_heatmap to print the top terms beside each module, or drawn on its own with enrichment_dotplot().

Usage

module_enrichment(obj, gene_sets, universe = NULL, gene_of = NULL,
  min_size = 5, max_size = 500, min_overlap = 2, p_adjust_method = "BH")

enrichment_dotplot(enrichment, top_n = 5, padj_cutoff = 0.05,
  base_size = 10, title = NULL, file = NULL, width = NULL,
  height = NULL)

Arguments

obj

A longi or multi_longi object.

gene_sets

Gene sets to test: a named list of gene vectors, a two-column data frame (term, gene), or the path to a GMT file.

universe

Background genes. Defaults to every gene in obj, which is appropriate when the object holds all tested genes. Supply the full set of measured genes when obj was built from a pre-selected subset such as differentially expressed genes.

gene_of

Optional function mapping feature IDs to gene symbols, for objects whose rows are not genes, e.g. function(id) sub("^.*_", "", id) for peak12_Cd8a. Ignored for multi_longi objects, which already carry gene symbols.

min_size, max_size

Gene sets with fewer or more genes in the universe are skipped.

min_overlap

Module / gene-set pairs sharing fewer genes are not tested.

p_adjust_method

Multiple-testing correction passed to p.adjust, applied across all tested pairs.

enrichment

The table returned by module_enrichment(), or any data frame with Cluster, Term, Padj, and FoldEnrichment columns (for example, results converted from another enrichment tool).

top_n

Number of terms shown per module, ranked by adjusted p-value.

padj_cutoff

Terms with a larger adjusted p-value are not shown.

base_size

ggplot base font size.

title

Optional plot title; none by default.

file

Optional output path (any ggsave() format).

width, height

Plot size in inches; scaled to the content when NULL.

Details

The test needs no annotation package: any collection of gene sets works, including pathway databases exported as GMT, transcription-factor targets, or custom marker lists, for any organism. Gene identifiers in gene_sets must use the same naming as the features of obj.

The choice of universe matters. Testing modules of pre-selected genes against only those genes asks "is this set concentrated in this module rather than the others?", whereas a universe of all measured genes asks "is this set enriched among the genes of this module at all?".

Value

module_enrichment() returns a data.table with one row per tested module / gene-set pair: Cluster, Term, Overlap, ModuleSize, SetSize, Universe, FoldEnrichment, PValue, Padj, and Genes (the shared genes), ordered by module and p-value.

enrichment_dotplot() returns a ggplot object, also saved when file is supplied.

See Also

longitudinal_heatmap, multi_heatmap

Examples

data("heatmap_example", package = "ModuleViz")
obj <- longitudinal_cluster(heatmap_example$mat, heatmap_example$meta,
                            time_col = "TimeHr", group_col = "Condition",
                            k = 4, stability = FALSE)
genes <- rownames(heatmap_example$mat)
sets <- list(Early_response = genes[1:15], Mid_response = genes[16:30],
             Late_response = genes[31:45],
             Housekeeping = genes[seq(2, 60, by = 4)])
enr <- module_enrichment(obj, sets, min_size = 3)
head(enr)

enrichment_dotplot(enr)

## top terms beside each module of the heatmap
longitudinal_heatmap(obj, enrichment = enr)
