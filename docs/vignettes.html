Vignettes

The package includes three Bioconductor-style vignettes. Each is rendered here with its code and figures.

Vignette Content
Complete user guide Every function, with options and figures.
Published CD8 T cell exhaustion workflow RNA-seq modules with H3K27ac and H3K27me3 CUT&RUN aligned by gene.
Longitudinal heatmap tutorial Bundled and public time-course data, single-cell and multi-omics examples.

After installation, the same vignettes open from R:

vignette("ModuleViz")
vignette("cd8-exhaustion-published-data")
vignette("longitudinal-heatmap-tutorial")

Runnable scripts for each workflow are in the examples/ folder of the repository.
